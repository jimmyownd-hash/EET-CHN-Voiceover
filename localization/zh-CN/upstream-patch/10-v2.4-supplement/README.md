# zh-CN supplement for OpenYAMM v2.4

Apply on top of v2.4 (`assets_dev/languages/zh-cn/text/`). Same files as 2.4, with:

- 201 engine.po + 83 mm9.po + 6 mm6.po + 1 mm7.po entries that are still empty or fuzzy in 2.4 filled in.
  Includes all Solo run / Talents / Keystones / Action bar / Quicksaves / Shops as lists / Potion warnings texts new in 2.4,
  and the 2.3 gaps (Battle Orders upkeep, Playthrough, "All continents", Quest Book, MAW artifact descriptions ...).
- "Elder {class}" -> 资深{class}.
- Harmondale: 和谐谷 -> 哈蒙代尔 (the usual transliteration), replaced in all ~170 places.
- Remaining empty entries are placeholders / debug strings / cipher text, not shown to players.

Not translated on purpose: `openyamm:fx/...` ids, `x: %d  y: %d`, the credits list, 18 mm6 single letters, ~200 MM9 script debug labels.
