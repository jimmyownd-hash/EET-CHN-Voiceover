# 2.8: MM9 formation rejection message

"The front line must be covered: nobody may stand behind an empty cell." was 前排必须站满：空格后面不能站人。 Players read the first half as "the front row needs three people" (it does not; the only rule is that nobody stands behind an empty cell of the same column, and a column may be empty). New text: 空格后面不能站人：某一列的前排没人，这一列后面也不能有人。
