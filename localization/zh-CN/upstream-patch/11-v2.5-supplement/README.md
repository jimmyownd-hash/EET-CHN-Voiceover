# zh-CN supplement for OpenYAMM v2.5

2.5 already contains our earlier zh-CN work (talents, class names, Harmondale, Arcomage sheet, 2.4 texts).
Only the strings new in 2.5 are still empty: Craftable stats option and description, "Item Bonus Power",
the item-name templates, and Action bar slot / Action Bar 1-10 key names.
`text/engine_zz-v2.5.po` fills them (loads after engine.po).

Also: "Talents" is rendered 专长 (not 天赋) in the solo-run UI, to avoid confusion with innate race abilities (能力) and skills (技能).
