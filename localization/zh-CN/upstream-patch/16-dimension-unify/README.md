# 2.8: one word for "dimension"

`text/engine_zz-v2.8.po` (14 entries): the same game feature was translated as 异界, 维度, 次元, 异次元, 位面 and 跨位面 in different places. All are now 次元: 次元地图, 次元门, 次元传送门 (unchanged), 次元挑战, 次元任务, 次元词缀, 次元传送.

The elemental planes of MM8 (火焰位面 etc.) are not touched; they are a different thing.
